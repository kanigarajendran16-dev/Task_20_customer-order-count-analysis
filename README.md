# Customer Order Count Analysis

## Veda Technology - Data Analytics Internship

### Task 20: Customer Order Count

This project analyzes customer ordering behavior using Python, Pandas, SQL, Excel and Plotly.

---

## Project Objective

The main objective is to:

- Count unique orders for each customer
- Identify frequent customers
- Handle duplicate order lines
- Analyze customer sales
- Analyze category-wise orders
- Create visualizations
- Build an interactive dashboard
- Perform SQL-based analysis
- Export analysis results

## Duplicate Order Handling

Some orders contain multiple product lines.

Therefore, the project uses:

`COUNT(DISTINCT Order_ID)`

and Pandas:

`nunique()`

to calculate the actual number of unique orders.
